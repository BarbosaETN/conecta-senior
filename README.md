# ConectaSênior

> Plataforma web voltada à inclusão digital e à segurança na internet para pessoas idosas.

## 📖 Sobre o projeto

O ConectaSênior é um projeto desenvolvido como parte da disciplina **Atividade Extensionista II – Tecnologia Aplicada à Inclusão Digital** do Centro Universitário Internacional UNINTER.

A plataforma tem como objetivo auxiliar pessoas idosas na utilização segura da internet por meio de conteúdos educativos, linguagem acessível e interface intuitiva.

## 🎯 Objetivos

- Promover a inclusão digital.
- Ensinar boas práticas de segurança na internet.
- Orientar sobre golpes virtuais.
- Incentivar o uso consciente da tecnologia.

## 🛠 Tecnologias

- HTML5
- CSS3
- JavaScript
